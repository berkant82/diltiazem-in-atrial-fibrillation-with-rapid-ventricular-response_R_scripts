# diltiazem-in-atrial-fibrillation-with-rapid-ventricular-response_R_scripts
R code that reproduces every number reported in a prospective emergency   department cohort study comparing weight-based low-dose diltiazem   (0.15 mg/kg), standard-dose bolus (0.25 mg/kg) and standard-dose infusion   (0.25 mg/kg over 10 minutes) for atrial fibrillation with rapid ventricular   response.
